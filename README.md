# SHROUD

A playable Python / pygame-ce ninja combat sandbox with movement, slashes, shuriken, deflection, sentries, and Shadow Echo.

Run `python main.py` after installing `requirements.txt`. Move with WASD/arrows, dash with Space, slash with J, and throw with K. Press P to pause, R to reset, and F1 for debug.

Run tests with `python -m pytest -q`. Detailed documentation and focused Echo tests arrive in stage 3.
